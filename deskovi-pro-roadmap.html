Principles

Three rules that decide what goes in and what stays out.

01

Local-first, including mail

Email goes directly between the store's own mailbox and its own server. A third-party relay is an optional extra, never the default. This is the sharpest contrast with tools that route mail through a cloud service.

02

WooCommerce-native

Every feature should use the order, the customer or the product. Generic helpdesk features are parity work; order-aware ones are where we can win.

03

AI proposes, a person decides

Bring your own key, mask personal data first, label drafts as drafts, and never send or refund automatically.

What stays Free, what is Pro

A promise to Free users, so the Pro launch never feels like a bait-and-switch.

Stays in Free
  • Tickets, guest access with order number + email, categories
  • Priority, bulk status and delete, CSV export
  • Agent assignment, canned replies, internal notes
  • Refund and resend-invoice from a ticket
  • Search, pagination, assignee filter
  • Email notifications from the store (wp_mail)
  • GDPR export and erase
Pro adds
  • Reply-by-email and mailbox connections
  • Rules, auto-assignment, SLA
  • Order-status deflection panel
  • Order-aware AI assistant
  • Reports, CSAT, retention rules
  • Merge, collision detection, custom fields, roles
  • Extra order actions, integrations, importers

Architecture

How Free and Pro fit together.

  • Two plugins. Free (WordPress.org) and deskovi-pro (sold through Freemius). Pro requires Free to be active and checks its version.
  • One direction of dependency. Pro registers into Free's extension points. Free never calls Pro code and never contains it.
  • Data ownership. Tickets, messages and attachments belong to Free. Pro-only data (mailboxes, rules, SLA timers, AI logs, reports cache) lives in Pro's own tables with its own version counter.
  • Vendor code. Composer libraries only in Pro, namespace-prefixed, with a committed lock file so releases can be audited.
  • PHP. Free stays on its current minimum. Pro may require PHP 8.1+.
  • Secrets. Encrypted at rest, never sent to the browser, never in logs.
  • Failure mode. If Pro breaks or the license lapses, Free keeps working exactly as before.

Quality gates for every Pro release

Lessons from the Free releases so far.

  • Scope check against the spec. Diff the delivered code against the written prompt. v1.3.0 arrived with two unrequested features; that must be caught before a release, not during review.
  • Upgrade-path test on a real site with existing data, not only a fresh install.
  • Live test of every money- or mail-touching feature (refunds, inbound mail, outbound mail) with real test accounts.
  • php -l and coding-standards pass, tsc, production build, zip hygiene (no .claude/settings.local.json, no stray vendor or dev files).
  • Security review for anything that accepts input from outside: inbound email, webhooks, REST routes (permission callbacks, nonces, rate limits, file validation).
  • Privacy: GDPR export and erase must cover Pro data; secrets redacted in every log.

Decisions needed before Phase 0

Recommendation first, alternatives underneath.

  1. Which phases form the public launch?Recommended: Pro 0.1 + 1.0 + 1.1 (email, automation, SLA, deflection). Alternative: launch after Pro 1.0 with email only, which is easier to ship but a thinner story next to SupportCandy and WSDesk.
  2. Mailbox sign-in method for the first releaseRecommended: Gmail and Microsoft OAuth plus generic IMAP. Alternative: generic IMAP with app-passwords only, faster but excludes many Microsoft 365 stores.
  3. AI billing modelRecommended: bring-your-own key only. Alternative: hosted credits later, which adds billing and customer-data responsibility.
  4. Price band (hypothesis, not validated)Fluent Support lists $129 per site per year; SupportCandy and WSDesk sit around $79–$149. A starting point to test: about $79–$99 for one site, about $179–$199 for five, no per-agent fees, with a launch discount.
  5. Free v1.4.0 scopeThe extension points must ship in Free before Pro can attach. Decide whether v1.4.0 is only that, or also carries the remaining Free items from the Free roadmap.
  6. Refund-style actions beyond FreeFree has full refund and resend-invoice. Decide whether line-item and partial refunds belong in Pro (current plan) or Free.
